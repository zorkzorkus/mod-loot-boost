# mod-loot-boost

An AzerothCore module that:

- gives bosses more loot, with a separate multiplier per instance size
  (dungeon, 10, 15, 20, 25 and 40 player raids, everything else),
  tier tokens included
- gives rare creatures more loot, with separate multipliers for
  dungeon rares and all other rares
- can let bonus items be copies of items that already dropped, with a
  configurable lower chance per instance size
- multiplies emblems
- raises the drop chance of BoE blues and epics everywhere

## Install

Copy the folder into `azerothcore/modules/` and (re)build.
